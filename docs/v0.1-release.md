# v0.1 Release Baseline

- Status: Closed
- Date: 2026-04-20

This document is the operator-facing closure note for Catalyst Continuum `v0.1`.
The detailed release boundary lives in [v0.1-scope.md](v0.1-scope.md).

## Shipped In v0.1

- structured brief intake, validation, and deterministic pack resolution
- durable run, task, artifact, and run-event state in Postgres
- Docker-first runtime-provider execution with enforced task timeouts
- worker control loop plus external-agent claim, heartbeat, and completion flow
- pack-driven repository generation for the baseline service, CLI, and worker packs
- durable artifact pipeline including backlog, dispatch, policy, quality, workspace snapshot, PR candidate, PR export, publication, and GitHub PR artifacts
- HTTP, CLI, and MCP surfaces over the same Rust command layer
- GitHub webhook intake, repository-signal handoff, and draft-PR promotion flow
- OpenTelemetry baseline with Collector, Prometheus, Tempo, Loki, and Grafana in the local stack
- external MCP capability-policy contract, upstream `Everything` interoperability checks, and documented `Fetch` guidance
- published persisted artifact schemas plus hardened run-event schema alignment
- template repository scaffolding for private-instance follow-on work

## Closed v0.1 Local Stack

The shipped local compose baseline for `v0.1` is:

- orchestrator
- postgres
- redis
- otel-collector
- prometheus
- tempo
- loki
- grafana

`LiteLLM` remains part of the broader architecture direction, but it is not a required bundled service in the closed `v0.1` compose baseline.

## Explicitly Not In v0.1

- Proxmox runtime-provider support
- Kubernetes runtime-provider support
- orchestrator-managed third-party MCP sidecar lifecycle
- generic MCP marketplace behavior
- duplication of native agent capabilities such as `git` or local filesystem access

## Validation Baseline

The release baseline should continue to pass these repository-standard checks:

- `./scripts/check-versions.sh`
- `./scripts/ci-compose.sh`
- `./scripts/ci-rust.sh`
- `./scripts/ci-smoke.sh`

On Apple Silicon, `act` remains useful for workflow-shape checks, but full Rust execution under `act` can still hit the known upstream `qemu`/`rustc` crash path.

## Next Scope

The next scoped feature cut is `v0.2`, focused on:

- Proxmox runtime-provider support
- Kubernetes runtime-provider support
- execution isolation hardening around those provider expansions
